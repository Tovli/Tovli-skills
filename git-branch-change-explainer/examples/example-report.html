Business changes

Previously, a missing invoice caused a search error. Now the search shows no matches.

01
Business outcome

An unsuccessful search shows no matches

Before this change, an unsuccessful invoice search showed an error.

After this change, the user sees that no invoice matches the search.

The user can change the search and try again.

BEFORE: When the invoice does not exist, the search shows an error.

Technical changes

Missing invoices change from HTTP 404 to an empty HTTP 200 result; InvoiceLookup takes ownership of that result.

Contract changes

Consumers must handle a successful empty response

BEFORE: InvoiceLookup.Find returns null when an invoice is missing.

BEFORE: GET /invoices/{id} maps that result to HTTP 404.

AFTER: InvoiceLookup.Find returns an explicit empty InvoiceSearchResult.

AFTER: The endpoint returns HTTP 200 with an empty items array.

Consumers that depend on HTTP 404 must change.
