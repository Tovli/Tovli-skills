# Security Policy

## Scope

This policy covers the skills and supporting files in this repository, including scripts, examples, and documentation.

## Report a vulnerability

Please report suspected vulnerabilities privately. If private vulnerability reporting is enabled for the repository, use the **Report a vulnerability** option in its GitHub Security tab. Otherwise, use a private contact channel published by the repository owner.

Do not open a public issue or pull request with exploit details, credentials, or sensitive data. Include the affected skill or file, the steps needed to reproduce the issue, its likely impact, and any suggested mitigation. Use sanitized examples.

Maintainers will review reports as capacity allows. This project does not currently publish a response-time guarantee.

## Supported versions

The latest content on the default branch is the supported version. Older copies may not receive security fixes.
