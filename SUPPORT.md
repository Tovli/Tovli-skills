# Support

For help with a skill:

1. Read the skill's `SKILL.md`, README, and examples.
2. Check that your agent supports the `SKILL.md` format and follow its installation instructions.
3. If you find a reproducible defect, open an issue with the skill name, agent and version, relevant steps, and expected result. Remove private data and credentials.

Use the feature request issue template to suggest a new skill or an improvement. Support is best effort; no response-time guarantee is provided. Behavior can differ between agent platforms.

Do not report security vulnerabilities in public issues. See [SECURITY.md](SECURITY.md) for private reporting guidance.
